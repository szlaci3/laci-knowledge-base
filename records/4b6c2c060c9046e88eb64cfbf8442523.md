# Software idea: Personalized daily audio learning

## Concept

Create software that turns various source materials and AI-curated content into text-to-speech audio lasting from tens of minutes to a few hours. The implementation approach is not yet known. The audio is intended for listening during physical activities such as cleaning, washing dishes, or walking.

## Feeding session and source material

The process starts with a feeding session between the user and an LLM, during which the user imports material, mostly text. Examples include information to memorize, technical explanations, and YouTube transcripts that need summarizing.

Combine imported material with AI-curated content. Based on what the LLM knows about the user and on specific configuration, it selects "What needs to be learned today." The AI selects and prioritizes content to fit the desired amount of listening time.

## Learning and content preparation

Some content repeats material selected a number of days earlier; apply spaced repetition to support memorization and memory refresh.

Allow text improvements and configuration, including the permitted level of language complexity, repeated sentences, chapter summaries, and musical breaks where useful. The listening experience should leave enough time to absorb the material.

## Uses

- Stay informed about technology news.
- Memorize material and refresh those memories over time.
- Revisit software the user developed a few days earlier, helping the user remember and understand their own software. A developer diary, potentially generated, could supply this material.

## Daily editing workflow

The content should be editable. For a new day, the user can choose to start from zero or begin with the previous day's content and add or remove material.

## Playback and controls

Provide play/pause and chapter or topic selection. Ideally, most playback interactions would be performed through AirPod taps.

## Inspiration

The user wishes they could listen more to ChatGPT's answers while washing dishes, without having to keep asking questions. The answers can be too fast and linguistically complex for that setting. Music between paragraphs could help create breathing room and make the experience easier to follow.
