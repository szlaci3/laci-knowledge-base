# Antigravity in n8n: pin the underlying Gemini version

My Antigravity integration in n8n uses an underlying Gemini model. When it moved from Gemini 3.7 to Gemini 3.8, the update introduced new features and broke my existing integration. Pinning Antigravity to Gemini 3.7 restored functionality.

For future work, pin each integration to the specific Gemini version it was built and tested against, and test upgrades before switching versions. This reduces the risk of unexpected breaking changes.
